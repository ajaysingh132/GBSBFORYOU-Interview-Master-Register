1. सामग्री की पहचान बनाएँ

हर सामग्री को एक अलग Asset ID मिलेगी। इसे संबंधित परियोजना, साक्षात्कार और प्रश्न से जोड़ें। फाइल को पहले Google Drive या अन्य विश्वसनीय स्टोरेज में अपलोड करें, फिर उसका साझा लिंक यहाँ दर्ज करें। यह GitHub Pages फॉर्म फाइल को अपने-आप क्लाउड पर अपलोड नहीं करता।

रिकॉर्ड अभी इस ब्राउज़र में सुरक्षित होंगे। नियमित JSON बैकअप डाउनलोड करें।

2. Asset Master Register

Asset ID स्वतः बनती है और रिकॉर्ड में स्थायी रहती है। डुप्लिकेट ID इम्पोर्ट होने पर उसे अलग ID दी जाएगी। एक डिवाइस/ब्राउज़र का localStorage अपने-आप दूसरे डिवाइस से साझा नहीं होता।

Asset IDपरियोजना / साक्षात्कार / प्रश्नप्रकार और फाइललिंकसत्यापन / अनुमतिकार्य

अभी कोई सामग्री दर्ज नहीं है।

3. पहचान ID का नियम

प्रदर्शित ID का रूप: AST-HR001-Q001-0001। ID परियोजना/साक्षात्कार/प्रश्न के संदर्भ के साथ बनती है; यदि समान संदर्भ में ID पहले से हो, तो अगला क्रमांक दिया जाता है। ID फाइल के नाम से स्वतंत्र है। रिकॉर्ड में स्टोरेज लिंक और सत्यापन स्थिति अलग रखी जाती है।
